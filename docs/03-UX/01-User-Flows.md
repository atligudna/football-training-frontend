# Purpose

This document describes how users move through Football Planner.

The application should feel natural to football coaches.

Navigation should follow the coaching workflow rather than the database structure.

---

# The Coaching Cycle

Football Planner is built around one continuous coaching cycle.

Plan

↓

Prepare

↓

Coach

↓

Review

↓

Reuse

Every feature in Football Planner belongs to one of these phases.

# Navigation Principles

Football Planner should require as few clicks as possible.

Important actions should always be available from the Dashboard.

Users should never feel "lost."

The application should always make it obvious what happens next.

---

# Guiding Principle

Football Planner should guide the coach through the training day.

The coach should never have to think about where to click next.
