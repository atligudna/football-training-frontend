# Purpose

The purpose of the MVP is to deliver a product that solves a real coaching problem.

Version 1.0 is complete when a football coach can prepare, run and reuse a complete football training session without using paper.

The MVP should focus on solving one problem exceptionally well rather than solving many problems partially.

---

# MVP Goal

A football coach should be able to:

- Create a training session.
- Build the session visually.
- Organise coaches.
- Run the session from a mobile phone.
- Save the session.
- Reuse the session later.

Everything else is secondary.

---

# Product Promise

Football Planner should become the primary workspace for football coaches.

Planning should become faster.

Running sessions should become easier.

Reusing knowledge should become effortless.

The application should allow coaches to spend more time coaching and less time managing.
